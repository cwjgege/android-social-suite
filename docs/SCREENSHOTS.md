# Screenshot checklist / 截图清单

Create screenshots at 1600 x 900 or higher. Use one consistent Windows theme and avoid showing unrelated desktop content.

## Required screenshots

1. `manager-main.png`: main manager with two sample phones, one running and one stopped.
2. `create-phone.png`: new-phone dialog showing the hardware profile selector.
3. `vless-binding.png`: VLESS dialog with the share link hidden; never reveal a real UUID, domain, key, or node name.
4. `media-drop.png`: manager drop area while dragging a safe sample image.
5. `emulator-home.png`: clean Android 14 home screen.
6. `gallery-album.png`: AndroidSocialSuite album containing neutral sample photos and videos.
7. `proxy-test.png`: successful proxy result with the exit IP partially blurred.
8. `apk-install.png`: successful installation message using a non-sensitive demo APK.

## Privacy requirements

- Blur Google accounts, social handles, notifications, contacts, IP addresses, VLESS UUIDs, server names, public keys, QR codes, and subscription URLs.
- Use demonstration accounts and copyright-safe sample media.
- Do not show customer data, browser history, local usernames, or unrelated desktop files.
- Review image metadata before publishing.

Place approved images in `docs/screenshots/`. README image blocks can be added after the final files are available.
